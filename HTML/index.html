Restaurante La Tortuga

Proyecto Equipo XX · Calculadora de cuentas en Java

¿Qué hace el programa?

Es un programa de Java para calcular la cuenta de un restaurante. Primero pregunta cuántas unidades quiere el cliente de cada plato. Después calcula el subtotal, le suma el 10 % de IVA y, si la cuenta supera los 50 euros, aplica un descuento del 5 %. Al final muestra el total a pagar.
